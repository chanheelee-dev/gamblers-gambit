# 03. Glossary

이 프로젝트에서 반복적으로 쓰는 기술 용어를 한 곳에 모은다. 본 문서는 정책상 **한국어 본문 + 영어 기술 용어** 를 쓰기 때문에, 다른 문서에서는 용어의 재정의 없이 이 파일을 참조하는 것을 원칙으로 한다.

> **작업 규칙**: 새 용어가 설계·리서치 문서에 등장하면, 해당 커밋에서 이 파일도 함께 업데이트한다.

형식: **용어** / 정의 / 이 프로젝트에서의 의미 / 참고.

---

## 평가와 단위

### Centipawn (cp)

체스 엔진(Stockfish 등)이 출력하는 포지션 평가 단위. 폰의 1/100. 부호는 관례적으로 백 관점. `+150cp` 는 백이 약 1.5 폰 우세.

- **이 프로젝트**: 내부 계산용. 플레이어에게 직접 노출하지 않는다.

### Winrate / Win Probability (wp, %)

현재 포지션에서 한쪽(문맥에 따라 백 또는 "수를 둔 쪽")의 기대 승률. 0~100 %.

- **이 프로젝트**: 표면에 노출되는 평가 단위. cp → wp 변환식은 `01-game-concept.md` §2 참조. 확정 전 후보 비교는 R2.

### Percent Point (pp)

두 wp 값의 차이를 표현하는 단위. "30 % → 45 %" 는 15 **pp** 상승. ("% 포인트") 와 "% 가 상승" 은 다른 개념 — 혼동 주의.

### 변동폭 (V)

어떤 수(move) 전후의 wp 변화 절댓값.

```
V = |wp_after − wp_before|    (단위: pp)
```

- **이 프로젝트**: 본 게임의 난이도 proxy. 작업가설상 V 가 클수록 플레이어 정답률 p 가 크다.

## 배당과 베팅

### Payout / Win payout

베팅을 맞췄을 때 받는 **순이익 배수** (베팅액 1 기준). 즉 베팅 10 유닛에서 `win_payout = 0.5` 면 맞췄을 때 +5 유닛을 받는다 (원금 10 유닛은 그대로 반환).

### Loss multiplier

베팅을 틀렸을 때 잃는 양의 배수 (베팅액 1 기준). `loss_mult = 1.5` 면 10 유닛 베팅 시 실제 손실은 15 유닛.

### Base odds / Fair odds

기대값(EV) 이 0 이 되는 이론적 배당. 정답률이 p 일 때 `base_odds = (1 − p) / p`. 하우스 엣지가 0 인 기준선.

### Skill tax (α, β)

공정 배당 위에 얹는 난이도 비대칭 파라미터.

- **α ∈ [0, 1]**: 쉬운 문제(큰 V)의 win_payout 축소율.
- **β ∈ [0, 1]**: 쉬운 문제의 loss_mult 증폭율.
- α = β = 0 → 공정 배당. 값이 클수록 "쉬운 건 짜게, 실수는 혹독히".

### 하우스 엣지 (House edge)

도박 운영자(house) 관점의 장기 기대수익률. 플레이어 관점에서는 매 베팅당 평균적으로 잃게 되는 비율.

```
house_edge = − EV_per_bet / bet_size
```

- 공정 배당이면 `house_edge = 0`.
- 본 프로젝트에서는 `skill tax (α, β)` 가 하우스 엣지의 손잡이. α = β = 0 → 엣지 0%, 키울수록 엣지 ↑.
- **의도**: V (난이도) 에 따라 엣지가 **비균일** 하다. 쉬운 구간(큰 V) 에서 엣지가 가장 크고, V→0 극한에서는 `s(V)→0` 이 되어 엣지가 0 에 가까워짐 — "어려운 문제는 공정에 가깝게 보상".
- 참고 수치: 블랙잭 ~0.5%, American 룰렛 ~5.3%, 슬롯 5~15%, 스포츠 베팅 vig ~5%.

### Baseline 정답률

베팅 형태별 "찍기" 기대 정답률.

- binary up/down → 0.5
- N-choice → 1/N
- numeric range → 구간 넓이에 의존

p(V) 모델에서 V=0 일 때의 상수항으로 쓰인다 (R5 참조).

## 난이도 신호 (tactical features)

### Blunder

큰 음(−) 의 V 를 만드는 수. 일반적으로 초보자에게도 잘 보이는, 명백한 실수.

### Sacrifice

단기적으로 material 을 손해 보지만, 수 뒤에 이득(또는 mate)이 나는 수. 본 게임에서는 "큰 V + material down" 형태로 표식 가능. **작업가설의 대표적 반례**: 큰 V 이지만 맞추기 어려움.

### Only move

두는 쪽에 유효한 대안이 사실상 없는 수. cp 2위 수와의 차이가 큰 경우. 난이도 ↑ 방향의 신호.

### Quiet move

공격/교환 없이 위치적으로 중요한 수. 보통 V 가 작지만, 틀릴 경우 뒤에 큰 V 가 연쇄적으로 터진다.

### PV (Principal Variation)

엔진이 예측한 최적 수순. 길이가 tactical obviousness 의 한 신호 (희생이 깊을수록 PV 가 길어지는 경향).

### Tactical obviousness

"사람 눈에 그 수가 얼마나 뻔히 보이는가" 를 가리키는 비공식 용어. 본 프로젝트에서는 p(V, features) 확장의 축으로 등장.

## 모델·수식

### p(V)

변동폭 V 에서의 기대 정답률. 초안:

```
p(V) = baseline + (1 − baseline) * (1 − exp(−λ * V))
```

- `baseline` 은 베팅 형태에 따라 0.5 또는 1/N (R5).
- `λ` 는 "V 한 단위당 난이도 감소 속도". 실측값은 R3.

### EV (Expected Value)

한 라운드 베팅의 기대 수익. 맞췄을 때 이득과 틀렸을 때 손실의 확률가중 합.

```
EV = p * win_payout  −  (1 − p) * loss_mult
```

- α = β = 0 이면 EV = 0 (공정).
- 본 게임은 의도적으로 EV < 0 (하우스 엣지) 이되, **"아예 베팅하지 않는 것보다는 낫도록"** α, β 를 제한.
